# Инструкции для Claude Code — tsunami-core

## Что это
Header-only **I/O фундамент** (парсеры/форматы/параметры/координаты/источники) в `include/`.
Решателя здесь НЕТ — он в [`tsunami-simulator`](https://github.com/NskTSH/tsunami-simulator).
Граница с потребителями (`tsunami-simulator`, `tsunami-ui`) — header-only исходная, НЕ DLL.

## Build & Test
- Сборки нет (header-only). «Тест» = заголовки компилируются у потребителей.
- CMake-таргет: `NskTSH::tsunami-io` (INTERFACE, добавляет `include/`).

## Правила
- Заголовки должны оставаться **самодостаточными** (только std + друг друга), без зависимости от решателя.
- Header-only = source ABI → изменение ломает сборку потребителей: помечать релизы SemVer-тегами.
- НЕ хардкодить `F:\`/абсолютные пути. Минимальные изменения > рефактор. Читать код перед правкой.

## Workflow
- Не коммитить/пушить без явной просьбы.
- Общение по-русски, код и комментарии на английском.
