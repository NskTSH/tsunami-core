# Инструкции для агентов — tsunami-core

## Назначение
Header-only **I/O фундамент** (парсеры/форматы/параметры/координаты/источники) в `include/`.
Решателя здесь нет — он в `tsunami-simulator`. Потребители (`tsunami-simulator`, `tsunami-ui`)
берут таргет `NskTSH::tsunami-io` как header-only исходную зависимость (НЕ DLL).

## Как верифицировать
- Сборки нет. CMake configure потребителя должен находить таргет `NskTSH::tsunami-io` и заголовки в `include/`.
- Заголовки самодостаточны: компилируются с одними std-инклюдами, без зависимости от решателя.

## Границы
- Не добавлять сюда код решателя/CUDA — только I/O-фундамент.
- Header-only = source ABI → менять заголовки осторожно (ломает сборку потребителей), помечать SemVer-тегами.
- Не трогать секреты, абсолютные пути.
